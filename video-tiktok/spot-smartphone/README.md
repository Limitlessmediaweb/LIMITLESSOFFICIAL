# ÈTERE One — spot smartphone (concept LIMITLESS)

ÈTERE è un **brand inventato**: telefono, nome e interfaccia sono creati da LIMITLESS. Ogni versione chiude con la riga "Concept LIMITLESS – ÈTERE è un brand inventato". Le tre caratteristiche ("Notte", "Titanio", "Giorni") sono frasi, senza numeri tecnici.

Stile `limitless-spot-prodotto` (lusso: fondo nero, luce dura laterale, una rim colorata) con il metodo `limitless-spot-cinema`. **Costo zero**: Three.js (MIT), HDRI Poly Haven (CC0), font Instrument Serif (OFL), clip Mixkit/Pexels gratuite per uso commerciale. Niente Higgsfield né servizi a pagamento.

## Musica e BPM
**100 BPM** — 1 beat = 0,6 s, ogni taglio dura 1 beat, 2 beat o mezzo beat. Scegli nell'app un audio di tendenza tra 98 e 102 BPM: il **drop** cade a **4,8 s** (social e YouTube) sulla rotazione del telefono e l'accensione dello schermo. Negli ads 15 s lo schermo si accende a 0,6 s. Le chiusure di social e YouTube tornano al nero del primo fotogramma (loop).

## Come rifarlo
```
npm install                          # three.js
node scripts/overlays.mjs            # testi -> overlays/<formato>/
python scripts/build.py              # stock -> render 3D -> montaggio -> out/
python scripts/build.py social       # una sola versione
```
- `3d/phone.js` — modello di ÈTERE One (titanio spazzolato anisotropo, vetro satinato, modulo fotocamera circolare con 3 lenti iridescenti e anello in rame, tasto con scanalatura).
- `3d/screen.js` — UI inventata (orologio, sfondo astratto animato, accensione, mirino della fotocamera).
- `3d/shots.js` — le inquadrature; `3d/main.js` — render ad accumulo (antialias, profondità di campo fisica, motion blur), AgX.
- `config.json` — takes, clip, grade, tagli e testi di ogni versione: per un altro prodotto si cambia qui.
